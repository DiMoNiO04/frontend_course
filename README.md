# 🖥️ Frontend Development Course[https://ulbitv.ru/frontend]

## 📖 Overview

This course offers a hands-on approach to frontend development through the step-by-step creation of a large, production-ready project. It focuses not only on React but also on a wide range of frontend development concepts, including infrastructure setup, testing environments, server interaction, and more. By the end of the course, you will have a technically complex project, extensive Git commits, and a reusable reference for implementing various features and approaches.

> **Note:** While React is a primary technology, this course emphasizes frontend development as a whole, making it suitable for developers using Vue, Svelte, Angular, or other frameworks (with some React-specific details).

## 🌟 Key Features

- **Over 45 hours** of concentrated video content.
- Weekly stream recordings (if included in the plan).
- Detailed step-by-step lessons covering real-world scenarios.

## 📚 Knowledge and Skills Gained

### Configuration
- Project setup from scratch: Webpack, Vite, Babel, SCSS, CSS modules, Prettier, Jest, Storybook, etc.
- Plugin and loader configuration with proper decomposition.
- Test environment setup: Jest, RTL, Storybook, Loki, Cypress.

### UI Components
- Development of **20+ UI components**: modals, dropdowns, sidebars, buttons, skeleton loaders, popups, and more.
- Accessible and semantic components.
- Custom and headless library solutions.

### Architecture
- Modular architecture: business entities, weak coupling, strong cohesion.
- Reuse and decomposition through practical examples.

### Optimization
- Performance optimization: bundle analysis, reducing re-renders, code splitting.
- Asynchronous components and Redux reducers.
- Throttle and debounce implementations.

### Real-World Tasks
- Building filters, search, sorting, infinite scrolling, comments, and multi-block pages.

### Styling and Theming
- CSS modules and theming with **three color schemes** (dark, light, orange).
- Easy extension to new themes.

### Testing
- **Storybook** setup with screenshot testing for regression testing.
- Unit testing with **Jest** and **React Testing Library**.
- E2E testing with **Cypress**, including custom commands and interceptors.

### Linting and Code Style
- Custom **ESLint** plugin development for enforcing architectural rules.
- Prettier and Stylelint setup.

### Error Handling
- Implementation of `ErrorBoundary` for effective error management.

### Routing
- **React Router v6**: role-based and authentication-based access control.
- Page splitting for minimal bundle size.

### Internationalization
- i18n integration with two languages (English and Russian).
- Chunked translation loading for smaller bundles.
- Handling plural forms.

### TypeScript
- TS configuration and integration with Webpack.
- Advanced TypeScript features: union types, generics.

### CI/CD and Deployment
- CI pipeline setup for testing, linting, and builds.
- Pre-commit hooks with **Husky**.
- Cloud server setup with **Nginx** and HTTPS configuration.
- Automated deployment scripts.

### Additional Topics
- Redux Toolkit and RTK Query for API interactions.
- Code generation scripts for feature scaffolding.
- Debugging tools: Network tab, React DevTools, Redux DevTools.
- Virtualization for performance improvement.
- Browserlist configuration for optimized bundles.
- Git flow vs. trunk-based development.
- Feature flags and dynamic user settings.
